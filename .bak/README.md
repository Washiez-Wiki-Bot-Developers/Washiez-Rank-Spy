# Washiez-Rank-Spy

A Discord Bot to notify changes on your favorite roleplay company.

---

## Overview

> This repository is to maintain our bot and syncs to PROD.
> Please use the portable edition, TO BE ADDED, for your monitoring purposes outside Washiez.

Washiez-Rank-Spy keeps an eye on rank changes to monitor changes in the Roblox Group using Roblox Group API V1.

## Key features

- **Rank tracking:** Continuously watches users or entities and detects promotions, demotions, and ties.

## Running this Bot

Running this bot is simple, all already configured for Washiez.

### 1. Installing all dependencies listed in requirements.txt.

Install all dependencies by running pip alike below:

```shell
pip install -r requirements.txt
```
